# 내 사진 자리

이 폴더의 `latest.jpg` 파일이 쇼츠 템플릿의 "내 코멘트" 씬(personal_photo_bg_text_overlay)에 자동으로 사용됩니다.

## 사용법

1. 본인 사진 파일을 `latest.jpg` 라는 이름으로 이 폴더에 넣고 커밋/푸시하세요.
   (세로 사진 권장, 9:16 비율이 가장 잘 어울립니다.)
2. 다음 날 자동 실행부터 바로 반영됩니다. 즉시 반영하려면
   `python scripts/pipeline.py` 를 수동으로 한 번 실행하세요.
3. 파일이 없으면 안내 문구가 담긴 플레이스홀더 이미지가 자동 생성되어 사용됩니다.
